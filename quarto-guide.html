📚 什么是 Quarto？

Quarto 是一个开源的科学和技术出版系统，由 RStudio 团队开发。它能够将单一源文件转换为多种格式，包括 HTML、PDF、Word、PowerPoint 等。

🎯 Quarto 的特点

  • 多格式输出： 一次编写，多种格式
  • Markdown 语法： 简单易学，所见即所得
  • 代码集成： 支持 R、Python、Julia 等多种编程语言
  • 响应式设计： 自动生成移动端友好的网站
  • 模板系统： 丰富的主题和模板选择

🚀 部署和发布

本地预览

# 安装 Quarto（如果未安装）
# 访问 https://quarto.org/docs/get-started/

# 预览网站
quarto preview

# 渲染网站
quarto render

# 发布网站
quarto publish

GitHub Pages 部署

# 1. 推送到 GitHub
git add .
git commit -m "更新网站"
git push origin main

# 2. 在 GitHub 仓库设置中启用 GitHub Pages
# Settings -> Pages -> Source: main branch /docs folder

Netlify 部署

# 1. 构建网站
quarto render

# 2. 将 _site 文件夹上传到 Netlify
# 或使用 Netlify CLI
npm install -g netlify-cli
netlify deploy

JavaScript 优化

// 延迟加载
window.addEventListener('load', function() {
  // 页面加载完成后执行的代码
});

// 防抖函数
function debounce(func, wait) {
  let timeout;
  return function executedFunction(...args) {
    const later = () => {
      clearTimeout(timeout);
      func(...args);
    };
    clearTimeout(timeout);
    timeout = setTimeout(later, wait);
  };
}

🐛 常见问题解决

问题 1：样式不生效

原因： CSS 优先级问题或选择器错误 解决： 检查 CSS 选择器，使用 !important（不推荐）或提高选择器优先级

问题 2：JavaScript 不工作

原因： DOM 元素未加载完成 解决： 使用 DOMContentLoaded 事件监听器

问题 3：图片显示异常

原因： 路径错误或图片格式不支持 解决： 检查图片路径，使用相对路径，确保图片格式正确

问题 4：响应式布局问题

原因： Bootstrap 类使用不当 解决： 检查网格系统类，使用正确的响应式类
